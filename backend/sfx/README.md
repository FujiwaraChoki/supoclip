# SFX library

Drop your own `.mp3`, `.wav`, `.m4a`, or `.ogg` sound effect files in this
directory (e.g. a whoosh or riser for hook openings) and they'll show up in
Settings → SFX Library and in the Hook tab's SFX picker.

No files are bundled here by default — sound effects are typically licensed
assets, so choose your own rather than relying on ones shipped in this repo.
